# Calculator App

This project is a simple beginner-level calculator written in Python.

## What it does

The script asks the user to enter:

- the first number
- the operation to perform
- the second number

Then it performs the selected arithmetic operation and prints the result.

## Supported operations

- addition
- subtraction
- multiplication
- division

## How it works

The program uses:

- input() to collect user data
- float() to convert values into numbers
- loops to validate invalid input
- if/elif statements to perform the correct calculation

## Example

```text
Enter first number: 10
Enter operation. Choose from (a)ddition, (s)ubtraction, (m)ultiplication, and (d)ivision: a
Enter second number: 5
Answer: 15.0
```

## Run it

From the same folder as the file, run:

```bash
python main.py
```

## Notes

This is a small learning project designed for beginners to practice Python fundamentals such as functions, user input, loops, and conditionals.
